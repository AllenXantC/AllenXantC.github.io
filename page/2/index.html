线段和或差的最值

发表于 2025-03-17 更新于 2026-08-20 分类于 数学 ， 初等数学

我们有两条线段：|AB|和|AC|，其中A在某个曲线上运动，B, C为定点。如果有人想知道两条线段长和的最小值，那显然就是B与C的连线长，因为

|AB|+|AC| ≥ |BC|

那如果要求最大值呢？因为上式只指出和的下限，所以要另寻办法。

我们知道，除了两边之和大于第三边以外，还有两边之差小于第三边的结论，这可以作为一个突破口，只需把其中一条线段换成差就行了。

假如

|AB2| = 2a − |AB1|

|AB1|+|AC| = 2a + |AC|−|AB1| ≤ 2a + |BC1|

线段差的最值同理。
